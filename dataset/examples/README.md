# Example Notebooks

This folder contains examples for reading sample datasets from the OpenMesh archive.

**Note:** These notebooks also exist in the Zenodo archive, but here they are updated with corrected paths to work within this repository structure.

**Available notebooks:**
- `openmesh_dataset_example.ipynb` – CML links visualization and exploration
- `read_pws_sample.ipynb` – Reading PWS sample data from NetCDF files

These notebooks use data extracted from the OpenMesh Zenodo archive. To get the data, run:

```
src/fetch_data/OpenMesh/download_and_read_openmesh.ipynb
```
